Database Sicuro GitHub

I tuoi dati sono custoditi al 100% nel tuo repository privato su GitHub. Inserisci le credenziali di accesso.

Il token risiede solo in locale nel tuo browser e comunica con GitHub via HTTPS.
Come creare il tuo Database Sicuro su GitHub:
  1. Crea un repository Privato su GitHub chiamato geem-data.
  2. Vai su Settings > Developer settings > Personal access tokens.
  3. Genera un token abilitando Contents: Read and write per geem-data.
  4. Incolla il token e clicca Connetti: la struttura dati verrà inizializzata all'istante.
