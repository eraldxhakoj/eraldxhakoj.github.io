Database Sicuro GitHub

I tuoi dati sono custoditi al 100% nel tuo repository privato su GitHub. Inserisci le tue credenziali per accedere.

Il token viene conservato solo nel tuo browser e comunica direttamente con GitHub via HTTPS.
Come creare il tuo Database Sicuro su GitHub:
  1. Crea un nuovo repository Privato su GitHub chiamato geem-data.
  2. Vai su Settings > Developer settings > Personal access tokens > Fine-grained tokens.
  3. Genera un token selezionando Only select repositories > geem-data con permesso Contents: Read and write.
  4. Incolla il token qui sopra e clicca Connetti: GEEM creerà automaticamente la struttura dati nel repository!
